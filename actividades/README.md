# Actividades

Esta carpeta contiene propuestas de aula, tareas y secuencias vinculadas con conciencia linguistica.

Formato sugerido para cada actividad:

1. Titulo.
2. Destinatarios.
3. Duracion estimada.
4. Objetivos.
5. Desarrollo paso a paso.
6. Evidencias de aprendizaje.
7. Variantes o adaptaciones.
8. Observaciones para el docente.
