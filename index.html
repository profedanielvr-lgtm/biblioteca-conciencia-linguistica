Uso para estudiantes y colegas

Esta página funciona como punto de entrada a la biblioteca. Los recursos se irán incorporando y organizando progresivamente en las secciones correspondientes.

Quien solo necesite consultar la biblioteca puede usar el enlace público de esta página.

Acceso para profesorado

Para modificar contenidos, el profesorado debe tener acceso como colaborador en GitHub. Una vez autorizado, podrá editar archivos desde el repositorio.
