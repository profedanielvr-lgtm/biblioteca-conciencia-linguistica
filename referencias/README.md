# Referencias

Esta carpeta organiza bibliografia, marcos teoricos, informes, articulos y fuentes relevantes sobre conciencia linguistica.

Formato sugerido:

1. Referencia en APA7.
2. Resumen breve.
3. Palabras clave.
4. Relevancia para la biblioteca.
5. Enlace o ubicacion del documento, si corresponde.

Nota: solo incluir materiales que puedan citarse o reutilizarse de forma adecuada.
