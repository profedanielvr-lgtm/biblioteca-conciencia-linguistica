# Materiales

Esta carpeta contiene materiales didacticos relacionados con conciencia linguistica.

Cada material deberia incluir, cuando sea posible:

1. Titulo del recurso.
2. Nivel o contexto educativo recomendado.
3. Objetivo de aprendizaje.
4. Instrucciones de uso.
5. Fuente o autoria.
6. Condiciones de reutilizacion.
